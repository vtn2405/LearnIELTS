# Dự án: Web_IELTS (Next.js + TypeScript)

## 🛠 Công nghệ sử dụng

- Framework: Next.js (App Router)
- Ngôn ngữ: TypeScript
- Stylings: Tailwind CSS
- Runtime: Node.js

## 🧠 Chỉ dẫn cho Claude

1. Luôn luôn ưu tiên viết code TypeScript chuẩn (không dùng `any`).
2. Khi sửa UI, hãy tuân thủ phong cách minimalist (tối giản) tương tự Huashu Design.
3. Nếu cần chạy test, hãy dùng `npm test` hoặc `npx jest` (tuyệt đối không chạy pytest vì đây không phải project Python).
4. Mọi yêu cầu code review phải tập trung vào React components và logic Next.js, không được review code Python hoặc các file không liên quan.

## 🛑 Danh sách lệnh an toàn

- Sử dụng: `npm run dev`, `npm run build`, `npm run lint`.
- Không được phép chạy các lệnh `python`, `pytest`, `pip`.
